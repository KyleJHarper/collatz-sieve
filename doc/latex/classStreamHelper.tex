\doxysubsection{Detailed Description}
Assists with serializing data, deserializing data, and providing feedback when failures occur without throwing. 

\begin{DoxyNote}{Note}
This class only writes in little-\/endian (it\textquotesingle{}ll {\ttfamily bwsap} for you), and expects data from sources in little-\/endian. 
\end{DoxyNote}

Deserialize any supported integral of type {\ttfamily T}. 

Will deserialize any integral of type {\ttfamily T}. When type is fixed-\/width, the caller is expected to deserialize using the same type to ensure the correct number of bytes are read, and therefore no size data is expected in the istream. When the type is variable length (mpz\+\_\+class), this will expect a sign, data size, and (if non-\/zero) limb data.

\begin{DoxyNote}{Note}
This method does not throw. Do not discard. 
\end{DoxyNote}
\begin{DoxyWarning}{Warning}
When using fixed-\/width, caller must use an explicit-\/width integral. Things like size\+\_\+t and int/uint are not portable. 
\end{DoxyWarning}
