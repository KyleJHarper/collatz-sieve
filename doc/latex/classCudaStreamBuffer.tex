Takes a kernel call reference, synchronizes buffers from host-\/to-\/device, and then executes the kernel. 

The kernel passed in MUST have this signature\+: {\ttfamily (T\texorpdfstring{$\ast$}{*}, Result\+Data\texorpdfstring{$\ast$}{*}, size\+\_\+t, cuda\+Stream\+\_\+t)}

Where\+:
\begin{DoxyItemize}
\item {\ttfamily T\texorpdfstring{$\ast$}{*}} will be the device buffer from this class.
\item {\ttfamily Result\+Data\texorpdfstring{$\ast$}{*}} will be the device result memory for your kernel to shared results.
\item {\ttfamily size\+\_\+t} will be the element count for your kernel to use with loops/boundaries.
\item {\ttfamily cuda\+Stream\+\_\+t} will be the pre-\/established stream for host\texorpdfstring{$<$}{<}-\/\texorpdfstring{$>$}{>}device synchronization.
\end{DoxyItemize}

\begin{DoxyNote}{Note}
This method injects a state change after the kernel. Caller should NOT set state directly.
