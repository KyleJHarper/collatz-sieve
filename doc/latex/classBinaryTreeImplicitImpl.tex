\doxysubsection{Detailed Description}
\subsubsection*{template$<$\mbox{\hyperlink{conceptAnySupportedIntegral}{Any\+Supported\+Integral}} T$>$\newline
class Binary\+Tree\+Implicit\+Impl$<$ T $>$}
A mathematically equivalent implimentation of a materialized {\ttfamily \doxylink{classBinaryTree}{Binary\+Tree}}. 

A mathematically equivalent analog to the {\ttfamily \doxylink{classBinaryTreeMaterializedImpl}{Binary\+Tree\+Materialized\+Impl}} approach. Nodes objects and other values are calculated on-\/the-\/fly instead of being stored in RAM.

Specifically, instead of a level map of all surviving nodes and a vector of pointers to them for each level, this implementation computes the values, detect coverage (HWM), and update a roaring bitmap. Tracking and iteration become implicit, hence this implementation\textquotesingle{}s namesake.

This implementation is vastly superior in almost every metric, and is the default as of version 4.\+0.\+0.

Add a level to the tree. 

Implicit tree building happens by tracking the left-\/to-\/right positions (not values) of nodes which haven\textquotesingle{}t been removed by a HWM node or ancestor. This is representatively identical to a materialized tree\textquotesingle{}s last level of nodes\+: anything remaining in the {\ttfamily \+\_\+uncovered\+\_\+positions} are the parent nodes from the previous level whose children must be processed.

To achieve any sort of threading performance, each thread will get thread-\/local storage (TLS) from an {\ttfamily \doxylink{structBinaryTreeImplicitImpl_1_1AddLevelTLS}{Add\+Level\+TLS}} struct, which includes its own {\ttfamily \doxylink{classNodeBitmap}{Node\+Bitmap}} and vector of ancestors (if tracking them). When all threading is finished, the results are merged into {\ttfamily \+\_\+uncovered\+\_\+positions}, coverage is calculated via simple arithmetic, and this function ends.

Threading itself is handed off to {\ttfamily Node\+Bitmap\+::for\+\_\+each\+\_\+transformer()}, along with the aforementioned callback (TLS) storage. This is in contrast to the {\ttfamily \doxylink{classBinaryTreeMaterializedImpl}{Binary\+Tree\+Materialized\+Impl}} which handles OMP directly inside the its own add level method. \Hypertarget{classBinaryTreeImplicitImpl_aecfa7613ef9e36c2e7f9da0f43d2dce7}\label{classBinaryTreeImplicitImpl_aecfa7613ef9e36c2e7f9da0f43d2dce7}
