{\footnotesize\ttfamily \mbox{\hyperlink{classNode}{constexpr}} \mbox{\hyperlink{classNode}{size\+\_\+t}} Exponents\+::\+MAX\+\_\+\+POW2\+\_\+\+UNDER\+\_\+\+POW3\mbox{[}\mbox{\hyperlink{namespaceExponents_accbaded6f43ce579264a5c9a760e9083}{MAX\+\_\+\+POW2\+\_\+\+UNDER\+\_\+\+POW3\+\_\+\+COUNT}}\mbox{]}\hspace{0.3cm}{\ttfamily [constexpr]}}



Table of powers of three and the resultant power of two which is still below that power of three. 

Powers of two and three quickly overflow data types, such as 64-\/bit overflowing at 3\texorpdfstring{$^\wedge$}{\string^}41. This table provides a method for determining the same thing\+: is a power of 2 below a power of 3?

It does this by using the array index as the exponent for powers of three, and the value of that element is the power of two which still remains below it.

For example, {\ttfamily MAX\+\_\+\+POW2\+\_\+\+UNDER\+\_\+\+POW3\mbox{[}4\mbox{]}} would return {\ttfamily 6}. The {\ttfamily 4} is three\textquotesingle{}s exponent\+: 3\texorpdfstring{$^\wedge$}{\string^}4. The {\ttfamily 6} is the maximum two\textquotesingle{}s exponent\+: 2\texorpdfstring{$^\wedge$}{\string^}6. When expanded, the result is\+: {\ttfamily 3\texorpdfstring{$^\wedge$}{\string^}4 \texorpdfstring{$>$}{>} 2\texorpdfstring{$^\wedge$}{\string^}6 ==\texorpdfstring{$>$}{>} 81 \texorpdfstring{$>$}{>} 64}. The next power of two would be {\ttfamily 128} and would fail the condition.

As a result, the entire array is simply a {\ttfamily size\+\_\+t} list and avoids type juggling.
