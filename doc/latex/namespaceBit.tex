\doxylink{namespaceBit}{Bit} manipulation functions.

Reverse the bits of any type {\ttfamily T} requested. Used largely for partial reversing later. 

The nature of the binary tree structure means certain liberties can be taken when calculating positions or node values within the tree, largely due to the constant power-\/of-\/two increase. To leverage this, one must take the bits from a node\textquotesingle{}s value or position and reverse them, but only a certain number of them on the LSB (least significant bit) side. There are many ways to do this, including a basic loop, which was used originally and then removed (diff 3.\+2.\+0). Ultimately compiler intrisics were and some black-\/box-\/ish helperes were built to speed this up since it\textquotesingle{}s a hot path.

\begin{DoxyWarning}{Warning}
This method does not support {\ttfamily mpz\+\_\+class}. The methods which would use it handle {\ttfamily mpz\+\_\+class} directly bit-\/by-\/bit. It is entirely possible to handle {\ttfamily mpz\+\_\+class} if needed some day, but it\textquotesingle{}s expensive and unnecessary.
\end{DoxyWarning}
