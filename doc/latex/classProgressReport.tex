\doxysubsection{Detailed Description}
Writes single or multi-\/line output to an ANSI-\/compliant terminal and erases it, assuming no wrapping. 

\begin{DoxyNote}{Note}
This is not thread safe and writes to stdout by default. 
\end{DoxyNote}
