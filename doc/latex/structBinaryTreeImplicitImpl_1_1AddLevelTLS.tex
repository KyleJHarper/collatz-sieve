struct Binary\+Tree\+Implicit\+Impl$<$ T $>$\+::\+Add\+Level\+TLS}
A thread-\/local cache structure for {\ttfamily \doxylink{classBinaryTreeImplicitImpl_af93247b2efa3579ee7a92a0529aae36c}{add\+\_\+level()}}. 

The {\ttfamily \doxylink{classNodeBitmap}{Node\+Bitmap}} has a multithreading (OMP) for-\/each iterator which we leverage to engage multiple CPUs when adding nodes to a level. This struct creates safety and scratch space for that.

\begin{DoxyWarning}{Warning}
This is not meant to be used anywhere else. 

Struct should be given alignas(...) to avoid false sharing. 
\end{DoxyWarning}
