\doxysubsection{Detailed Description}
An accelerated map which only tracks the {\ttfamily A} portion of\+: {\ttfamily Ax + b}. 

The distribution of ℕ over Harper\textquotesingle{}s tree, along with the application and limitation of {\ttfamily F} and {\ttfamily G} steps, create constant portions (B) which cannot overcome an associated contractive exponential portion (A) to bring the calculated value above itself.

In other words\+:
\begin{DoxyItemize}
\item Given f = number of F steps
\item Given k = number of F and G steps
\item Given A = 3\texorpdfstring{$^\wedge$}{\string^}f/2\texorpdfstring{$^\wedge$}{\string^}k
\item When A \texorpdfstring{$<$}{<} 1, then\+: A \texorpdfstring{$\ast$}{*} N + B \texorpdfstring{$<$}{<} N
\end{DoxyItemize}

While possibly asymptotic, this has been empirically validated up to 10,000 serial {\ttfamily F} steps. For safety, a counter has been added to ensure this class throws an exception above that level.

The ability to discard the B-\/portion means only the contractive nature of {\ttfamily A} matters. These have been precomputed and stored in {\ttfamily Exponents\+::\+MAX\+\_\+\+POW2\+\_\+\+UNDER\+\_\+\+POW3}.

\begin{DoxyNote}{Note}
This class has no calculate method, because the B-\/portion isn\textquotesingle{}t tracked. 

Due to the nature of this class, no type {\ttfamily T} is necessary or possible. 
\end{DoxyNote}
