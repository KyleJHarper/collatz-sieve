\doxysubsection{Detailed Description}
Creates an ostream subclass and connects it to a {\ttfamily \doxylink{classzstd__ostreambuf}{zstd\+\_\+ostreambuf}} so it may be passed around like a normal ostream. 

This class largely just wraps the {\ttfamily \doxylink{classzstd__ostreambuf}{zstd\+\_\+ostreambuf}} to make writing ZSTD data easier.
