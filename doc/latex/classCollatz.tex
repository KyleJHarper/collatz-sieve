\doxysubsection{Detailed Description}
\subsubsection*{template$<$\mbox{\hyperlink{conceptAnySupportedIntegral}{Any\+Supported\+Integral}} T$>$\newline
class Collatz$<$ T $>$}
A small object with metadata for a \doxylink{classCollatz}{Collatz} sequence. Mostly used for its static methods. 

This class will, upon initialization via the constructor or {\ttfamily \doxylink{classCollatz_a33c0998331a6f9e2b655bed17e85e873}{init()}}, set the metadata for a \doxylink{classCollatz}{Collatz} sequence starting at the specified {\ttfamily \+\_\+initial\+\_\+value}.

Originally, sequences were stored in-\/memory, but this blows out cache lines, and is generally useless. The for\+\_\+each iterators are so fast it\textquotesingle{}s almost never useful to cache them. If callers want them cached, they must do so externally, with a vector or similar.
