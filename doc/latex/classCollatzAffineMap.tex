\doxysubsection{Detailed Description}
\subsubsection*{template$<$\mbox{\hyperlink{conceptAnySupportedIntegral}{Any\+Supported\+Integral}} T$>$\newline
class Collatz\+Affine\+Map$<$ T $>$}
An explicit map which tracks 2\textquotesingle{}s and 3\textquotesingle{}s exponents ({\ttfamily A}) and the constant portion ({\ttfamily B}) for affine transformation. 

An FG chain can be stored and represented as an affine map with powers of two and three, and with a constant portion. This avoids any realtime tracking of fractional values (floats).

There are overflow concerns, which are most extreme when the chain is all {\ttfamily F} steps. This worst case leaves {\ttfamily constant\+\_\+portion} equal to {\ttfamily \texorpdfstring{$\sim$}{\string~}3\texorpdfstring{$^\wedge$}{\string^}k}. Each power of three needs \texorpdfstring{$\sim$}{\string~}1.6 bits to represent this in binary, so we have the following limits\+:
\begin{DoxyItemize}
\item 64-\/bits) 40
\item 128-\/bits) 80
\end{DoxyItemize}

Therefore, when using large maps, callers must be aware of overflow risks. These 40 and 80 limits are available via the {\ttfamily \doxylink{namespaceExponents_ad7383a96a7e056891ed183acd52262ce}{Exponents\+::\+POW3\+\_\+64\+BIT\+\_\+\+ELEMENT\+\_\+\+COUNT}} and {\ttfamily \doxylink{namespaceExponents_a4ac8c74d1070fa6be0de5d66997d2b49}{Exponents\+::\+POW3\+\_\+128\+BIT\+\_\+\+ELEMENT\+\_\+\+COUNT}}.
