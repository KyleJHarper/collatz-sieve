\doxysubsection{Detailed Description}
Compares integrals, booleans, and other data types, and reports differences to {\ttfamily \+\_\+err\+\_\+ptr}, optionally. 

This class exists to help compare two pieces of data and expects them to be identical. It will treat inequality as an error and write it to the {\ttfamily \+\_\+err\+\_\+ptr} if specified. A category can be set too, in the event equality is being tested in several areas of code or objects.
