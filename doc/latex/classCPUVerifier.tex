Entry point for the {\ttfamily \doxylink{classVerifier}{Verifier}} base class to begin actual execution of number verification. 

In this CPU implementation, this is actually just a dispatcher. It takes the runtime policy choices and makes a single call to the {\ttfamily \doxylink{classCPUVerifier_a3c932d95f7c56491a092f67343481634}{run\+\_\+executor\+\_\+impl()}} with the neccessary compile-\/time constants. This avoids if/else blocks inside hot loops which adds anywhere from 1-\/2\% up to 10-\/20\% performance in testing. 

Implements \mbox{\hyperlink{classVerifier_a76a2dc13fc257c2765b108c7b0b06a0f}{Verifier$<$ T $>$}}.
