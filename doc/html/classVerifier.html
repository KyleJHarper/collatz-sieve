Detailed Description

template<AnySupportedIntegral T>
class Verifier< T >

A base class behind the verification implementation classes. Provides the start, stop, resume, and so forth to manage the state and monitor the progress of a verification process. Actual implementation details are defined in the subclasses.

Template Parameters
TAny supported integral (see concepts.hpp).

◆ _synchronization_countdown

template<AnySupportedIntegral T>
size_t Verifier< T >::_synchronization_countdown = 100'000
protected

How many verifications a thread should do before synchronizing: checking for state changes and updating metrics.

Note
Benchmarking showed almost no difference between 1,000 - 100,000,000 on the CPUVerifier. It's set lower to favor responsiveness. Also, the GPU version uses kernel launches as its synchronization point, not this.
