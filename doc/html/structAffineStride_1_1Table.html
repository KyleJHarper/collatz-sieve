Detailed Description

template<size_t bits>
struct AffineStride::Table< bits >

A struct of constexpr stride data including a table, mask, and size based on bits. Empirical testing shows that bit sizes between 8-12 are most optimal, but the real threshold is L1 cache. When it spills over into L2, performance drops.

Template Parameters
bitsThe number of bits to build the table. Final table size is 2^bits. Blows up compilers ~16+.
