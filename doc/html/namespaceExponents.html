◆ MAX_POW2_UNDER_POW3

constexpr size_t Exponents::MAX_POW2_UNDER_POW3[MAX_POW2_UNDER_POW3_COUNT]
constexpr

Table of powers of three and the resultant power of two which is still below that power of three.

Powers of two and three quickly overflow data types, such as 64-bit overflowing at 3^41. This table provides a method for determining the same thing: is a power of 2 below a power of 3?

It does this by using the array index as the exponent for powers of three, and the value of that element is the power of two which still remains below it.

For example, MAX_POW2_UNDER_POW3[4] would return 6. The 4 is three's exponent: 3^4. The 6 is the maximum two's exponent: 2^6. When expanded, the result is: 3^4 > 2^6 ==> 81 > 64. The next power of two would be 128 and would fail the condition.

As a result, the entire array is simply a size_t list and avoids type juggling.

Note
The associated file "tools/pow2_under_pow3.py" helps build this table.
