Detailed Description

template<FixedWidthIntegral T>
struct GPUVerifier< T >::ThreadStorage

Thread-Local storage, mostly for wake-up call tracking and metrics.

For GPUs, this also includes a CudaStreamBuffer object. Since OMP has implicit barriers which were intentionally leveraged at the prefix level in the parallel iterator, AB-BA deadlocks can occur if ANY blocking synchronization technique attempts to coordinate threads within a for_each iterator. For this reason, each thread gets its own buffer to fill, submit, and wait on without barriers from others.

Warning
Data tends to spill cache lines and cause false sharing. Do NOT remove alignas(64).
