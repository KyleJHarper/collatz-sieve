Detailed Description

A multi-step (stride) of accelerated Collatz functions F and G stored as an affine map.

Since affine maps remain affine under composition, "striding" maps can be built for any N whose least significant bits match the composition which created the map. When thrown into a table, a process can stride "k" steps at a time with a single application of the accelerated map.
