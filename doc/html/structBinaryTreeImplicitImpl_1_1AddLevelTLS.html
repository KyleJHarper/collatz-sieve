Detailed Description

template<AnySupportedIntegral T>
struct BinaryTreeImplicitImpl< T >::AddLevelTLS

A thread-local cache structure for add_level().

The NodeBitmap has a multithreading (OMP) for-each iterator which we leverage to engage multiple CPUs when adding nodes to a level. This struct creates safety and scratch space for that.

Warning
This is not meant to be used anywhere else.
